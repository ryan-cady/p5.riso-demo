Circle Grid

A beginner-level sketch combining three basics: a nested loop, one RISO ink color, and exporting. Press "e" to export the layer as a PNG.

View CodeDownload Sketch

How it works

This sketch is meant to be read top to bottom — every line is commented to explain what it does. It draws a 6×6 grid of pink circles using a nested for loop, all on a single RISO ink layer, and lets you export that layer with a keypress.

Setting up

let pink; // will hold our one RISO ink layer

function setup() {
  createCanvas(600, 600);
  pixelDensity(1);
  noLoop();

  pink = new Riso("fluorescentpink");
}

createCanvas() makes the drawing surface. pixelDensity(1) keeps one pixel in the sketch equal to one pixel in the exported file. noLoop() tells p5 to run draw() exactly once instead of 60 times a second — this sketch doesn't animate, so there's nothing to gain from looping. new Riso() creates one ink layer, stored in the variable pink.

Picking the RISO color

pink = new Riso("fluorescentpink");

The string passed to new Riso() is the ink name — this sketch uses "fluorescentpink", one of 81 available colors. See the full RISOCOLORS list, or try swapping in any other name, like "blue" or "yellow".

The nested loop

let cols = 6;
let rows = 6;
let spacing = width / cols;

for (let row = 0; row < rows; row++) {
  for (let col = 0; col < cols; col++) {
    let x = col * spacing + spacing / 2;
    let y = row * spacing + spacing / 2;

    pink.noStroke();
    pink.fill(255);
    pink.circle(x, y, spacing * 0.6);
  }
}

A single for loop can only count in one direction — to cover a grid, which has two directions, one loop goes inside another. The outer loop counts row from 0 to 5; for every single row, the inner loop counts col all the way from 0 to 5 before the outer loop moves on. That's 6 rows × 6 columns = 36 circles total.

spacing divides the canvas width by the column count, so col * spacing lands each circle in its own cell, and + spacing / 2 centers it there instead of drawing from the corner.

Drawing on the layer

pink.noStroke();
pink.fill(255);
pink.circle(x, y, spacing * 0.6);

Shapes drawn with pink. in front go onto the pink ink layer instead of the canvas directly — see layer.circle() / .rect() / …. pink.fill(255) sets full ink density; lower numbers print lighter, halftoned ink.

Compositing and exporting

clearRiso(); // top of draw()
// ...draw the grid...
drawRiso();  // end of draw()

function keyPressed() {
  if (key === "e") {
    exportRiso();
  }
}

clearRiso() wipes the layer clean before drawing — without it, redraws would stack on top of each other. drawRiso() composites the layer onto the canvas so it's actually visible; nothing appears without this call. keyPressed() runs once every time a key goes down — checking key === "e" means only the E key triggers exportRiso(), which saves the layer as a PNG.
