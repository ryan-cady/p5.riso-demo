Random & Noise

Two ways to introduce variation in p5.js — random() for unpredictable scattered values, and noise() for smooth, organic variation.

random()

random() returns a different number every time it's called. With no arguments it returns a value between 0 and 1. Pass a max, or a min and max: 

random()         // 0 to 1
random(100)      // 0 to 100
random(50, 200)  // 50 to 200
for (let i = 0; i < 40; i++) {
  let x = random(width);
  let y = random(height);
  let d = random(20, 80);
  pink.fill(255);
  pink.circle(x, y, d);
}

Picking from an Array

Pass an array to random() to pick a random element from it: 

let inkNames = ["fluorescentpink", "blue", "yellow", "teal"];
let chosen = random(inkNames); // picks one at random

let sizes = [20, 40, 60, 80, 100];
let d = random(sizes);

randomSeed()

By default, random() gives different results every run. randomSeed(n) locks the sequence — the same seed always produces the same values: 

function setup() {
  createCanvas(825, 1275);
  pixelDensity(1);
  noLoop();
  randomSeed(42); // same layout every run
}

For a space-to-regenerate pattern, use a variable seed so each press generates a new layout that can still be reproduced: 

let seed = 1;

function draw() {
  randomSeed(seed);
  clearRiso();
  for (let i = 0; i < 50; i++) {
    pink.fill(255);
    pink.circle(random(width), random(height), random(20, 80));
  }
  drawRiso();
}

function keyReleased() {
  if (key === " ") {
    seed = floor(random(10000));
    redraw();
  }
  if (key === "e") exportRiso();
}

Seeding is important for RISO work — it lets you export exactly the composition you previewed.

noise()

noise() also returns values between 0 and 1, but adjacent inputs produce similar outputs — the values flow smoothly rather than jumping around. This makes it ideal for organic, natural-looking variation.

Pass a steadily-changing value to get smooth drift: 

let t = 0;

function draw() {
  clearRiso();

  let x = noise(t) * width;
  let y = noise(t + 100) * height; // offset avoids correlated x/y

  pink.fill(255);
  pink.circle(x, y, 60);
  drawRiso();

  t += 0.005; // small step = slow drift; larger step = faster
}

2D Noise Fields

Pass both x and y coordinates (scaled down) to get a smoothly varying value at every point on the canvas: 

function draw() {
  clearRiso();
  for (let x = 0; x < width; x += 40) {
    for (let y = 0; y < height; y += 40) {
      let n = noise(x * 0.005, y * 0.005); // 0–1, smoothly varying
      let d = n * 60;
      pink.fill(255);
      pink.circle(x, y, d);
    }
  }
  drawRiso();
}

The scale factor (0.005) controls how zoomed in you are on the noise field. Smaller = broader, smoother variation. Larger = tighter, more rapid variation.

noiseSeed()

Like randomSeed(), noiseSeed(n) locks the noise field to a fixed pattern: 

noiseSeed(99); // same noise field every run

random() vs noise()

  • random() — each call is independent with no relationship to the last. Good for scattered positions, random sizes, picking from a list.
  • noise() — nearby inputs give nearby outputs. Good for organic shapes, flowing motion, and anything where adjacent values should feel connected.
