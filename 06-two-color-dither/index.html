Two-Color Print

Dither + halftone on two Riso layers — simulates a two-drum print. Press 1/2 to adjust threshold.

View CodeDownload Sketch

How it works

Two Riso layers overlapping — pink (dithered) and blue (halftoned) — simulating a two-drum print. Press 1 to increase or 2 to decrease the dither threshold and find a look you like, then press "e" to export.

Two layers = two-color print

pink = new Riso("fluorescentpink");
blue = new Riso("blue");

Each layer becomes a separate PNG on export. On a real Risograph, each gets printed with a different ink drum. Where layers overlap, the colors mix — the on-screen preview simulates this.

Key controls

if (key == "1") {
  threshold = constrain(threshold + 10, 50, 200);
  redraw();
}
if (key == "2") {
  threshold = constrain(threshold - 10, 50, 200);
  redraw();
}

threshold starts at 125 and steps by 10 each key press. constrain() keeps it clamped between 50 and 200 so it can't go out of range. The sketch uses noLoop() so it only redraws when you press a key — this prevents the browser from processing the dither and halftone 60 times per second.

Halftone parameters

let halftoned = halftoneImage(img, "circle", frequency, 45, 100);

halftoneImage() takes five arguments:

  • Image — the source photo
  • Shape — "circle", "ellipse", "square", "line", or "cross"
  • Frequency — dot density (higher = smaller, tighter dots)
  • Angle — rotation of the dot grid in degrees
  • Intensity — effect strength (0–255)

Exporting for print

exportRiso();

Press "e" to save one PNG per layer. Each file is grayscale — the RISO operator assigns ink colors at the machine. White = no ink, black = full ink.
