How it works

A CSV (Comma-Separated Values) file is the most universal data format — any spreadsheet can export one. p5's loadTable() reads a CSV and turns it into a structured object you can loop through. Each row becomes one visual column in the print; each column in the spreadsheet controls a different visual property.

The CSV file (data.csv)

title,artist,year,bpm,energy,warmth
Bitches Brew,Miles Davis,1970,116,87,72
Trans-Europe Express,Kraftwerk,1977,116,61,40
Planet Rock,Afrika Bambaataa,1982,128,95,55
Blue Lines,Massive Attack,1991,92,68,58
...

The first row is the header — the column names. Every row below it is one data record. Numbers stay as numbers, text stays as text. CSVs can hold any data: survey responses, sensor readings, census numbers, sports stats. Swap in your own spreadsheet and the pattern changes completely.

Step 1: load the table in preload()

let table;

function preload() {
  // "csv"    = parse as comma-separated values
  // "header" = treat the first row as column names
  table = loadTable("data.csv", "csv", "header");
}

Like loadJSON() and loadImage(), loadTable() inside preload() finishes before setup() runs. The resulting table object holds all the rows.

Step 2: loop through the rows

let rowCount = table.getRowCount();  // number of data rows (not counting header)

for (let i = 0; i < rowCount; i++) {
  let row = table.getRow(i);  // one row at a time
  ...
}

getRowCount() gives you the number of rows. getRow(i) returns a p5.TableRow object — a single record from your spreadsheet. i is the row index, starting at 0.

Step 3: read values from a row

let title  = row.getString("title");   // text column → string
let bpm    = row.getNum("bpm");        // numeric column → number
let energy = row.getNum("energy");
let warmth = row.getNum("warmth");

Use getString() for text values and getNum() for numbers. The argument is the column name from your header row — so the column order in the file doesn't matter, only the names do. If you rename a column in your CSV, you rename it here too and everything still works.

Step 4: map values to visual parameters

let dotSize = map(energy, 0, 100, 3, 26);  // energy → dot diameter
let spacing = map(bpm,   60, 180, 40, 9);  // BPM → gap between dots

// warmth > 55 → pink layer, warmth ≤ 55 → blue layer
let layer = (warmth > 55) ? pink : blue;

The same map() pattern from earlier demos converts raw data into drawing parameters. The ranges (0–100 for energy, 60–180 for BPM) come from the actual data min/max — look at your CSV to find the right input range. The ternary operator (? :) is a compact if/else: if warmth is above 55, use pink; otherwise use blue.

Step 5: draw one column per row

let x = (i + 0.5) * colW;  // center of this column
let layer = (warmth > 55) ? pink : blue;

layer.noStroke();
layer.fill(220);

let y = spacing / 2;
while (y < height - 55) {   // dots from top to bottom of the column
  layer.circle(x, y, dotSize);
  y += spacing;
}

Each row in the table becomes one vertical column on the canvas. The while loop places dots from the top of the canvas downward, incrementing y by spacing each time. High BPM → small spacing → many dots per column. Low BPM → large spacing → few dots, more open.

What the data says

Press r to toggle between record titles and raw numbers. You can read the pattern like a chart:

  • Dense columns (many small gaps) = high BPM records — Aphex Twin (145), Burial (138), M.I.A. (140)
  • Sparse columns (large gaps) = slow records — Madvillainy (88), Donuts (93), Blue Lines (92)
  • Large dots = high energy — M.I.A. (98), Madvillainy (90), Planet Rock (95)
  • Pink = warm records — Bitches Brew, Since I Left You, Arular, Donuts
  • Blue = cool records — Kraftwerk, Aphex Twin, Burial

Swap in your own CSV and the same sketch becomes a completely different print. The structure stays the same — only the data changes.

Using your own data

To use your own dataset, replace data.csv with any CSV file. The rules:

  1. First row must be column names (the header)
  2. Numeric columns should contain only numbers — no units, no % signs
  3. Update the column names in row.getString() / row.getNum() to match your header
  4. Update the map() input ranges to match your data's actual min/max

Google Sheets → File → Download → CSV. Excel → Save As → CSV. Any tool that handles data can export a CSV.

Not sure what columns your CSV has or what ranges to put in map()? Drop it into the Data Cruncher — it shows min, max, and average for every column and generates a ready-to-paste sketch.
