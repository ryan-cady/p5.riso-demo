Intro to p5.riso

Color channels, drawing to layers, compositing

How it works

This sketch introduces the basic p5.riso workflow — creating color layers, drawing shapes to them, and compositing the result.

The Riso workflow

Every p5.riso sketch follows the same three steps inside draw():

  1. clearRiso() — wipe all layers clean
  2. Draw to your Riso layers
  3. drawRiso() — blend all layers together and display the result

If you forget clearRiso(), layers stack on themselves and go solid. If you forget drawRiso(), nothing shows up.
