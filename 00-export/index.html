Exporting for Print

How to export your p5.riso sketch as print-ready files — canvas sizing, resolution, layer export, and what to hand off to the printer.

Canvas Size & Resolution

RISO prints at 150 DPI by default (some machines go higher). To calculate your canvas size, multiply your print dimensions in inches by the DPI: 

// Half-letter: 5.5" × 8.5" at 150 DPI
createCanvas(825, 1275);

// Letter: 8.5" × 11" at 150 DPI
createCanvas(1275, 1650);

// A5: 5.8" × 8.3" at 150 DPI
createCanvas(870, 1245);

// A4: 8.3" × 11.7" at 150 DPI
createCanvas(1245, 1755);

Always set pixelDensity(1) in setup(). Without it, Retina/HiDPI screens will double the canvas resolution and break your export dimensions. 

function setup() {
  createCanvas(825, 1275); // half-letter at 150 DPI
  pixelDensity(1);         // required — never skip this
  noLoop();
}

exportRiso()

Call exportRiso() to download your print files. It saves one PNG per ink layer plus a composite preview. Most sketches trigger this with a key press: 

function keyReleased() {
  if (key === "e") exportRiso();
}

The files download automatically to your browser's downloads folder. You'll get:

  • One grayscale PNG per Riso layer — e.g. fluorescentpink_0.png, blue_1.png
  • A composite PNG showing all layers together — composite.png

The layer PNGs are the print files. The composite is for reference only.

Use noLoop() Before Exporting

If your sketch animates or redraws continuously, the exported frame might not be the one you want. Call noLoop() in setup() to draw once and stop — then press your export key when the composition looks right.

For sketches with a space-to-randomize pattern, combine both: 

function setup() {
  createCanvas(825, 1275);
  pixelDensity(1);
  noLoop();        // draw once and stop
}

function keyReleased() {
  if (key === " ") redraw();      // new composition
  if (key === "e") exportRiso();  // export current composition
}

File Naming

The exported layer files are named after your new Riso() color name and their index: colorname_0.png, colorname_1.png, etc. Use clear, descriptive color names so the printer operator knows which file goes with which drum. 

let pink = new Riso("fluorescentpink"); // → fluorescentpink_0.png
let blue = new Riso("blue");            // → blue_1.png

What to Send to the Printer

Hand off the individual layer PNGs — one file per ink color. Include:

  • The layer PNG for each ink (e.g. fluorescentpink_0.png and blue_1.png)
  • The ink color name for each file so the operator can load the right drum
  • The composite PNG as a reference for how the final print should look
  • Paper stock, if you have a preference

The layer PNGs are grayscale — black areas will print in ink, white areas won't. Don't convert them to color before sending.

Bleed

If your design runs to the edge of the paper, add a bleed — extra artwork that extends beyond the trim line — so there's no white edge if the cut is slightly off. A standard bleed is 0.125" (about 19px at 150 DPI) on each side. 

// Half-letter with 0.125" bleed on all sides:
// 5.5" + 0.25" = 5.75"  →  5.75 × 150 = 862px wide
// 8.5" + 0.25" = 8.75"  →  8.75 × 150 = 1312px tall
createCanvas(862, 1312);
pixelDensity(1);

Checking Your Export

Before sending to print, open each layer PNG and verify:

  • The file is grayscale — no color tint
  • The canvas dimensions match your intended print size at 150 DPI
  • Artwork fills the canvas correctly — no unexpected white borders or clipping
  • Dithered or halftoned areas look as expected at 100% zoom
