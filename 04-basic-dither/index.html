Basic Dither

Apply Atkinson dither to an image on a Riso layer

View CodeDownload Sketch

How it works

Converts a photo into a dithered dot pattern on a single Riso layer — simulating a one-color RISO print.

Creating a Riso layer

let black = new Riso("black");

This creates a Riso layer — think of it as a separate transparency. Everything drawn to this layer becomes one color channel. On a real Risograph, each layer is one ink drum pass.

The dither + draw workflow

clearRiso();
let dithered = ditherImage(img, "atkinson");
black.image(dithered, 0, 0);
drawRiso();

ditherImage() converts a continuous-tone photo into pure black and white pixels using a pattern algorithm. "atkinson" is the classic Macintosh dither — high contrast with a retro, textured look.

Notice you're drawing to the Riso layer (black.image()), not the main canvas. That's the key difference from regular P5.

Ink density, not color

When using fill() on a Riso layer, the value (0–255) controls ink density, not color. The color was already set when you created the layer with new Riso("black").
