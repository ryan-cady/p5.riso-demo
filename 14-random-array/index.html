Randomize Array

Same 10-element array as demo 13 — shuffled and sampled on each draw. Press space for a new composition. Each seed picks 5 items and arranges them into a different layout.

View CodeDownload Sketch

How it works

Demo 13 showed a fixed array drawn in order — deterministic, always the same. This demo asks: what if you shuffle the array and draw only a subset? The same 10 items become a generative system. Change the seed and you get a completely different selection and arrangement.

shuffle() — reorder an array randomly

// shuffle() returns a new array with the same items in a random order.
// The original data[] array is not changed.
let shuffled = shuffle(data);

// slice(0, 5) takes the first 5 items from the shuffled list —
// a random subset with no repeats.
let selected = shuffled.slice(0, 5);

Slicing the first N items after shuffling is a clean way to pick a random subset without repeating anything. Change 5 to any number up to data.length.

randomSeed() — reproducible results

let seed = 42;

function draw() {
  randomSeed(seed); // reset the sequence at the start of every draw
  let selected = shuffle(data).slice(0, 5);
  // ...
}

Without randomSeed(), every call to random() and shuffle() pulls from an unpredictable sequence — good for live animation, bad for reproducible prints. randomSeed(n) resets the sequence to a known starting point, so the same seed always produces the same shuffle and the same composition.

Calling randomSeed() at the very top of draw() ensures the entire drawing is locked to one seed.

Picking a new seed

function keyReleased() {
  if (key === " ") {
    // This random() runs outside draw(), after randomSeed() has expired,
    // so it draws from the system's unseeded RNG — truly unpredictable.
    seed = floor(random(9999));
    redraw();
  }
}

The key insight: seed = floor(random(9999)) runs after draw() has finished, outside the seeded context — so it gives a genuinely new, unpredictable number each time. That new seed then locks the next composition.

random(array) — pick one item

let names = ["sub", "kick", "bass", "pad", "lead"];
let pick = random(names); // one item chosen at random

Pass an array to random() and it returns one element at random. Useful for picking a random color, a random record from your data, or a random word from a list.

The difference from demo 13

  • Demo 13 — fixed array, drawn in order. Add/remove items and the layout updates, but the arrangement never changes.
  • Demo 14 — same array, shuffled and sampled. One dataset, many possible compositions. The data is the material; the seed is the arrangement.

This is also the same pattern used in demo 11 — the only difference is that demo 11 loads its data from a CSV file instead of a hardcoded array.

Using your own data

Replace the data array with any array of objects. The pattern stays the same: shuffle, slice, seed. Use the Data Cruncher to generate a ready-to-paste array from any CSV file.
