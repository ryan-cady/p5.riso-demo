Setting Up p5.js

Two ways to work: the browser-based p5.js editor (nothing to install) or a local setup with VS Code and Live Server. Both work with p5.riso.

Option A — p5.js Web Editor

The fastest way to start. No installation required — everything runs in the browser at editor.p5js.org.

1. Create an account

Go to editor.p5js.org and sign up for a free account. This lets you save and share your sketches.

2. The default sketch

Every new sketch starts with a sketch.js that has setup() and draw() already in place. Click the play button (▶) to run it. 

function setup() {
  createCanvas(400, 400);
}

function draw() {
  background(220);
}

3. Adding p5.riso

The web editor doesn't load p5.riso automatically. To add it, open the file sidebar (click the > arrow on the left), then click the dropdown arrow next to your sketch name and choose Add file. Name it p5.riso.js.

Paste the full contents of the p5.riso library into that file.

Then open index.html and add the script tag inside <head>, after the p5.js script tag: 

<script src="p5.riso.js"></script>

4. Saving and sharing

Use File > Save (or Ctrl+S / Cmd+S) to save your sketch. To share it, click File > Share — you'll get a link that anyone can open to view or remix your sketch.

Uploading images

If your sketch uses loadImage(), open the file sidebar, click the dropdown, and choose Upload file. Once uploaded, reference it by filename only — no path needed: 

function preload() {
  img = loadImage("my-photo.jpg"); // just the filename
}

Option B — VS Code + Live Server

Better for larger projects, working with local files, or using your own images. Requires a one-time install.

1. Install VS Code

Download Visual Studio Code and install it. It's free and works on Mac, Windows, and Linux.

2. Install the Live Server extension

p5.js sketches must run on a local server — opening index.html directly as a file won't work because browsers block certain features (like loadImage()) on file:// URLs.

In VS Code, open the Extensions panel (Cmd+Shift+X) and search for Live Server by Ritwick Dey. Install it.

3. Create your project folder

Make a new folder anywhere on your computer. Inside it, create two files: 

my-sketch/
├── index.html
└── sketch.js

4. Set up index.html

This file loads p5.js and p5.riso from a CDN — no local library files needed. Paste this into index.html: 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <script src="https://cdn.jsdelivr.net/npm/p5@1.9.0/lib/p5.js"></script>
  <script src="https://cdn.jsdelivr.net/gh/antiboredom/p5.riso/lib/p5.riso.js"></script>
</head>
<body>
  <script src="sketch.js"></script>
</body>
</html>

5. Write your sketch

Open sketch.js and start writing. Here's the minimal p5.riso boilerplate: 

let pink, blue;

function setup() {
  createCanvas(600, 800);
  pixelDensity(1);
  noLoop();

  pink = new Riso("fluorescentpink");
  blue = new Riso("blue");
}

function draw() {
  clearRiso();

  pink.fill(200);
  pink.circle(300, 400, 200);

  blue.fill(180);
  blue.rect(100, 300, 400, 200);

  drawRiso();
}

6. Launch Live Server

Right-click index.html in the VS Code file explorer and choose Open with Live Server. Your sketch opens in the browser at localhost:5500. Every time you save a file, the browser reloads automatically.

Working with images locally

Put your image files in the same folder as your sketch (or a subfolder like images/), then reference them by relative path: 

img = loadImage("my-photo.jpg");      // same folder
img = loadImage("images/photo.jpg");  // inside an images/ subfolder

Other Text Editors

Any text editor works as long as you pair it with a local server. Some options:

  • Sublime Text — use the SublimeServer package
  • WebStorm / other JetBrains IDEs — have a built-in local server; right-click index.html and choose Open in > Browser
  • Terminal / command line — run python3 -m http.server from your sketch folder, then open localhost:8000 in your browser

Tips

  • Always use pixelDensity(1) in setup() when working with p5.riso — it prevents display scaling from affecting exports
  • Load images in preload(), not setup() — p5 waits for preload() to finish before running anything else
  • Open the browser console (Cmd+Option+J on Mac, F12 on Windows) to see error messages when something isn't working
  • Use noLoop() when your sketch only needs to draw once — it's faster and makes exportRiso() more predictable
