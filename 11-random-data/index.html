Random Data

Same dataset as demo 10 — but shuffled and sampled each time. Press space to regenerate. Each seed picks 5 random records and scatters them into a new composition.

How it works

Demo 10 mapped every CSV row to a fixed column — deterministic, one layout. This demo asks a different question: what if you randomly sample the data and place it freely? The same dataset becomes a generative system: one seed, one print. Change the seed, get a completely different poster.

random(low, high) — a value in a range

let x = random(80, width - 80);   // a random x position
let y = random(80, height - 80);  // a random y position

random(low, high) returns a float anywhere between low and high. Each call is independent — calling it twice gives two different numbers. This is how we scatter cluster centers unpredictably across the canvas.

random(array) — pick one element

let names = ["bulbasaur", "snorlax", "jolteon"];
let pick = random(names);  // one of the three, chosen at random

Pass an array to random() and it returns one element chosen at random — equivalent to names[floor(random(names.length))] but much shorter. Useful for picking a random color, a random record from a dataset, or a random word from a list.

shuffle(array) — reorder randomly

let rows = [];
for (let i = 0; i < table.getRowCount(); i++) {
  rows.push(table.getRow(i));
}

// shuffle() returns a new array — the original is unchanged
let shuffled = shuffle(rows);

// Take the first 5 of the shuffled list = a random subset
let selected = shuffled.slice(0, 5);

shuffle() returns a new array with the same items in a random order. Slicing the first N elements after shuffling is a clean way to pick a random subset without repetition — each element appears at most once. Here we pick 5 of the 10 records; which 5 depends entirely on the current seed.

randomSeed(n) — reproducible randomness

let seed = 42;

function draw() {
  randomSeed(seed);  // reset the sequence at the start of every draw
  // ...every random() call now follows the same path for this seed
}

function keyReleased() {
  if (key === " ") {
    seed = floor(random(9999)); // pick a genuinely new seed
    redraw();
  }
}

Without randomSeed(), every call to random() pulls from a different point in an unpredictable sequence — good for live animation, bad for reproducible prints. randomSeed(n) resets the sequence to a known starting point, so calling the same code with the same seed always produces the same result. Calling randomSeed() at the top of draw() ensures the whole composition is locked to one seed.

The key insight: the final seed = floor(random(9999)) in the keypress handler runs outside the seeded context (after draw() has finished), so it draws from the system's unseeded RNG — truly random, giving a new unpredictable seed each time.

Mapping data to a scattered layout

let clusterR = map(energy, 0, 100, 20, 80);      // energy → cluster spread
let dotCount = floor(map(bpm, 60, 180, 5, 22));  // BPM → dot count
let dotSize  = map(energy, 0, 100, 4, 18);       // energy → dot size

for (let i = 0; i < dotCount; i++) {
  let a = random(TWO_PI);   // random angle
  let d = random(clusterR); // random distance from center
  layer.circle(x + cos(a) * d, y + sin(a) * d, dotSize);
}

The data still controls the visual properties — energy drives cluster size and dot diameter, BPM drives how many dots appear. But now position is free. The same record placed with seed 100 looks completely different from seed 200 because x and y are random. The data is the shape; the seed is the composition.

Using your own data

Swap in any CSV or JSON array. The key pattern is:

  1. Load your data (CSV or JSON) in preload()
  2. Convert rows/items into a plain JS array
  3. shuffle() the array and slice() a subset
  4. Use random() for position and map() for size/shape driven by data values
  5. Wrap everything in randomSeed(seed) so any composition can be reproduced
