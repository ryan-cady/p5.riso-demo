Variables & Conditionals

How to store values in variables and make decisions with if/else — two of the most fundamental building blocks in JavaScript.

Variables

A variable stores a value so you can use it later. In JavaScript, declare variables with let or const: 

let x = 100;       // can be changed later
const size = 50;   // fixed — never changes

Use const when the value won't change. Use let when it will. 

let x = 100;
x = x + 10; // fine — x is now 110

const size = 50;
size = 60;  // ✗ error — const can't be reassigned

Scope

A variable declared inside a function only exists inside that function. To use a variable across multiple functions (setup(), draw(), etc.), declare it at the top of the file: 

let img;           // declared at top — visible everywhere

function preload() {
  img = loadImage("photo.jpg");
}

function draw() {
  image(img, 0, 0); // works — img is in scope
}
function setup() {
  let count = 0;   // only exists inside setup()
}

function draw() {
  count++;         // ✗ error — count is not defined here
}

if / else

An if statement runs a block of code only when a condition is true: 

if (x > width) {
  x = 0; // reset when x goes off the right edge
}

Add else for what to do when the condition is false, and else if to check additional conditions: 

if (x > width) {
  x = 0;
} else if (x < 0) {
  x = width;
} else {
  x = x + 2;
}

Comparison Operators

x === y   // equal (use === not ==)
x !== y   // not equal
x > y    // greater than
x < y    // less than
x >= y   // greater than or equal
x <= y   // less than or equal

Always use === (triple equals) for comparisons in JavaScript — it checks both value and type. == can produce unexpected results.

Logical Operators

Combine conditions with && (and), || (or), and ! (not): 

if (x > 0 && x < width) {
  // x is on screen
}

if (key === " " || key === "r") {
  redraw(); // redraw on space OR "r"
}

if (!isExporting) {
  draw(); // only draw if not currently exporting
}

Boolean Variables

A boolean holds either true or false. Useful as flags to track state: 

let showGrid = false;

function keyReleased() {
  if (key === "g") {
    showGrid = !showGrid; // toggle on/off
    redraw();
  }
}

function draw() {
  clearRiso();
  if (showGrid) {
    drawGrid();
  }
  drawRiso();
}
