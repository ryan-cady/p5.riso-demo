Dither & Halftone

RISO prints in binary — each dot of ink is either fully on or fully off. Dithering and halftone convert continuous-tone images into dot patterns that simulate shading and photography.

Why It's Necessary

A RISO drum can't vary ink density mid-print. To reproduce the appearance of a gradient or photograph, p5.riso converts your image into a field of dots — areas with more dots look darker; areas with fewer look lighter. The two main techniques for doing this are dithering and halftone.

ditherImage()

ditherImage() converts an image into a scattered dot pattern using an error-diffusion or threshold algorithm. Call it on a Riso layer: 

let img;
let pink;

function preload() {
  img = loadImage("photo.jpg");
}

function setup() {
  createCanvas(825, 1275);
  pixelDensity(1);
  noLoop();
  pink = new Riso("fluorescentpink");
}

function draw() {
  clearRiso();
  pink.ditherImage(img, "atkinson");
  drawRiso();
}

Dither Modes

The second argument to ditherImage() sets the algorithm:

  • "atkinson" — the default. Spreads error to nearby pixels, producing a high-contrast, graphic result with strong blacks and whites. Loses some midtone detail but reads well in print.
  • "floyd" — Floyd-Steinberg. Spreads error more evenly than Atkinson, preserving more midtone detail. Finer texture, closer to a photographic feel. Can look slightly muddy in very dark areas.
  • "ordered" — Bayer matrix dither. Produces a regular, grid-like pattern. The structure is visible and gives a retro screen-print look. Less naturalistic, more graphic.
  • "random" — random threshold per pixel. Noisy, high-contrast, gritty. Detail is lost but the texture is raw and unpredictable.
  • "horizontal" / "vertical" — threshold lines running horizontally or vertically. Produces a striped, scan-line aesthetic.
  • "blob" — clusters dots together into irregular blobs. Looser and more organic than ordered dither.
  • "square" — threshold in a square tile pattern. Geometric and regular.

See the Dither Comparison demo to preview each mode side by side.

halftoneImage()

Halftone converts an image into a regular grid of dots whose size varies with the brightness of the original. It's the technique used in traditional offset printing and newspapers. 

pink.halftoneImage(img, frequency, angle);
  • frequency — how many dot rows per inch (roughly). Lower = bigger dots, more visible grid. Higher = finer grid, more detail. Try values between 10 and 40.
  • angle — rotation of the dot grid in degrees. 45° is the classic halftone angle. Changing the angle between layers in a two-color print reduces moiré patterns.
// Classic halftone:
pink.halftoneImage(img, 20, 45);

// Two-color with offset angles to reduce moiré:
pink.halftoneImage(img, 20, 45);
blue.halftoneImage(img, 20, 75);

Dither vs. Halftone — When to Use Each

  • Dither — better for photographs and images with a lot of tonal variation. The scattered dot pattern reads as natural and photographic. Atkinson is a safe default.
  • Halftone — better when you want a visible, structured dot pattern as part of the aesthetic. The grid is legible and graphic. Great for portraits, bold images, or a deliberately retro look.

Tips for Better Results

  • Start with a high-contrast image — dithering compresses the tonal range. An image that already has good contrast will survive the conversion better than a flat, low-contrast photo.
  • Resize your image to match the canvas — if your image is much smaller than the canvas, the dither pattern will be scaled up and look chunky. Load an image at or above your canvas resolution.
  • Test at 100% zoom — dither patterns look different at screen scale vs. actual print size. Preview your exported PNG at 100% to see what will actually print.
  • Fluorescent inks dither beautifully — fluorescent pink and lime produce especially vivid dithered images because their saturation stays high even at partial coverage.
  • Adjust brightness before dithering — use tint() or image filters to lighten or darken the source image before passing it to ditherImage(). This shifts where the midtone threshold falls.
