How it works

An array is an ordered list of values. In p5.js you declare one with square brackets — the same syntax JavaScript uses everywhere. Each slot is a value you can read back later by its index.

A plain number array

let sizes = [10, 40, 25, 60, 15];

// sizes[0] → 10  (first element, index 0)
// sizes[2] → 25  (third element, index 2)
// sizes.length → 5  (how many elements)

Indexes start at 0, so the last element is always at arr.length - 1. .length tells you how many elements are in the array — you never need to hard-code that number.

Looping over an array

for (let i = 0; i < sizes.length; i++) {
  let s = sizes[i];       // current element
  let x = i * 60 + 30;   // position based on index
  circle(x, 300, s);
}

This is the core loop pattern for data-driven sketches. i is both the array index and the position counter. As i goes from 0 to sizes.length - 1, sizes[i] steps through every element in order.

Arrays of objects

const data = [
  { label: "sub",  val: 82, warm: false },
  { label: "kick", val: 61, warm: false },
  { label: "bass", val: 74, warm: true  },
  // ...
];

Each element can itself be an object with multiple named properties. This lets one array carry several values per item — a label, a number, a boolean — and you read them by name instead of position.

Reading properties inside the loop

for (let i = 0; i < data.length; i++) {
  let item = data[i];         // the whole object at index i
  let val  = item.val;        // 0–100
  let warm = item.warm;       // true or false

  let dotSize = map(val, 0, 100, 4, 28);
  let spacing = map(val, 0, 100, 38, 9);
  let layer   = warm ? pink : blue;

  // ... draw column of dots
}

The loop body stays the same no matter how many elements are in data. Add or remove entries from the array at the top of the sketch and the drawing updates automatically — you never touch the loop.

When to use each approach

  • Literal array — good for small, fixed datasets you control entirely. Easy to tweak individual values directly in the sketch.
  • CSV file — better for larger datasets, data that changes, or data that came from a spreadsheet. Swap the file and the sketch redraws itself.
