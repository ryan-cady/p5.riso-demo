Setting Up p5.riso

The exact <head> tags and setup() calls a page needs before you can draw with p5.riso.

1. Add the script tags

p5.riso extends p5.js — it has to load after the p5.js script tag, not before. Put both in <head>: 

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <script src="https://cdn.jsdelivr.net/npm/p5@1.9.0/lib/p5.js"></script>
  <script src="https://cdn.jsdelivr.net/gh/antiboredom/p5.riso/lib/p5.riso.js"></script>
</head>
<body>
  <script src="sketch.js"></script>
</body>

Swap the order and new Riso() throws an error, since p5.riso is looking for a p5 object that hasn't loaded yet.

Working in the p5.js web editor instead? It doesn't load p5.riso automatically — see Setting Up p5.js for the extra step of adding it as a file.

2. The setup() checklist

Every p5.riso sketch needs these four lines before it can draw anything:

let pink, blue;

function setup() {
  createCanvas(825, 1275); // print size at 150 DPI
  pixelDensity(1);
  noLoop();

  pink = new Riso("fluorescentpink");
  blue = new Riso("blue");
}
  • createCanvas(w, h) — sized to your print dimensions at 150 DPI. See Exporting for Print for the conversion table.
  • pixelDensity(1) — without this, Retina/HiDPI screens double the canvas resolution and your exported PNGs come out the wrong size.
  • noLoop() — optional, but recommended for single-print pieces. It stops draw() after one frame, which keeps exportRiso() predictable.
  • new Riso("colorname") — one call per ink layer. See the full RISOCOLORS list for every available name.

3. The draw() shape

Layers get wiped, drawn to, then composited — in that order, every frame. See Intro to p5.riso for the full explanation. 

function draw() {
  clearRiso();

  pink.fill(200);
  pink.circle(300, 400, 200);

  blue.fill(180);
  blue.rect(100, 300, 400, 200);

  drawRiso();
}
