Working with Fonts

How to load and use custom fonts in p5.js — from Google Fonts and local font files — and how to draw type on Riso layers.

Two Ways to Load Fonts

p5.js gives you two approaches depending on where your font is coming from: CSS (for web fonts like Google Fonts) or loadFont() (for local font files).

Option A — Google Fonts via CSS

The simplest approach for Google Fonts. Add the font's <link> tag to your index.html head, then reference the font by name in your sketch — no loadFont() needed.

In index.html: 

<!-- paste the Google Fonts link tag in <head> -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Space+Mono:wght@400;700&display=swap" rel="stylesheet">

Then in sketch.js, just use the font name as a string: 

function draw() {
  textFont("Space Mono");
  textSize(48);
  fill(0);
  text("Hello", 100, 200);
}

Go to fonts.google.com, select a font, click Get font, then Get embed code — copy the <link> tag into your HTML.

Option B — Local Font Files with loadFont()

For fonts you've downloaded (.ttf or .otf files), use loadFont() in preload(). p5.js needs to fetch and parse the file before drawing anything, so it must be in preload(). 

let myFont;

function preload() {
  myFont = loadFont("fonts/MyFont-Regular.ttf");
}

function setup() {
  createCanvas(825, 1275);
  pixelDensity(1);
  noLoop();
}

function draw() {
  clearRiso();

  textFont(myFont);
  textSize(64);

  let pink = new Riso("fluorescentpink");
  pink.fill(255);
  pink.textFont(myFont);
  pink.textSize(64);
  pink.text("RISO", 100, 300);

  drawRiso();
}

Put your font file in the same folder as your sketch (or a fonts/ subfolder) and reference it by relative path.

Text on Riso Layers

To draw text on a Riso ink layer, call the text functions on the layer object instead of globally: 

let blue = new Riso("blue");

blue.fill(255);            // ink density — 255 = full coverage
blue.textFont("Space Mono");
blue.textSize(72);
blue.textAlign(CENTER, CENTER);
blue.text("GLITCH", width / 2, height / 2);

Text drawn to a Riso layer renders in that ink color. The layer ignores the global fill — always set layer.fill() separately.

Text Properties

textFont("Space Mono");       // font family
textSize(48);                 // size in pixels
textStyle(BOLD);              // NORMAL, BOLD, ITALIC, BOLDITALIC
textLeading(60);              // line height (for multi-line text)

textAlign(LEFT);              // horizontal: LEFT, CENTER, RIGHT
textAlign(LEFT, TOP);         // + vertical: TOP, CENTER, BASELINE, BOTTOM

// Measure a string before drawing it:
let w = textWidth("Hello");
let h = textAscent() + textDescent(); // approximate line height

Multi-Line Text

Pass \n inside a string for a line break, or use the optional width parameter on text() to wrap automatically: 

// Manual line breaks:
text("Line one\nLine two\nLine three", x, y);

// Auto-wrap inside a box — text wraps at the given width:
text("A longer piece of text that will wrap automatically.", x, y, 400);

Tips for Print Typography

  • Use larger type than you think — dithering and halftone dot patterns can make fine type hard to read at small sizes
  • Avoid two-color text — misregistration will make fine letterforms blurry; put text on a single layer
  • High-contrast works best — bold, wide type in a single ink color reads cleanly; light weights and thin strokes are risky
  • Test with noFill() / noStroke() — toggling these helps isolate whether your text settings are taking effect

Finding Fonts

  • Google Fonts — free, large library, easy to embed via CSS
  • Velvetyne — independent French foundry, free open-source typefaces
  • Open Foundry — curated open-source typefaces
  • DaFont — large library, check individual font licenses before use
