Image Array

Multiple images loaded into an array, dithered, and scattered randomly across the canvas. Press space for a new layout — each seed is a different composition.

View CodeDownload Sketch

How it works

Earlier demos load one image. This demo puts multiple images into an array and loops through them — the same pattern you'd use for a zine, poster, or any layout with more than one photo. Each image is dithered and placed on a Riso layer at a random position and size.

Loading multiple images in preload()

const imagePaths = [
  "photo-1.jpg",
  "photo-2.jpg",
  "photo-3.jpg",
  // add more here
];

const SHOW_COUNT = 2; // how many to show at once

let images = [];

function preload() {
  for (let i = 0; i < imagePaths.length; i++) {
    images[i] = loadImage(imagePaths[i]);
  }
}

All images are loaded upfront in preload(). Add new paths to imagePaths and the loop handles them automatically. SHOW_COUNT controls how many appear on each draw — the rest are loaded but not used until the next shuffle.

Picking a random subset

// shuffle() reorders the array randomly.
// slice(0, SHOW_COUNT) takes the first N from the shuffled list —
// a random subset with no repeats.
let selected = shuffle(images).slice(0, SHOW_COUNT);

This is the same pattern from demo 14. Every press of space picks a new seed, which means a new shuffle — different images, different positions, different sizes.

Resizing once in setup()

function setup() {
  // ...
  for (let i = 0; i < images.length; i++) {
    images[i].resize(400, 0); // 400px wide, height scales automatically
  }
}

Resizing in setup() means it happens once, not on every frame. Passing 0 as the second argument preserves the aspect ratio — p5 calculates the height automatically.

Dithering and drawing each image

for (let i = 0; i < images.length; i++) {
  let img = images[i];

  // Even indexes → pink layer, odd → blue
  let layer = i % 2 === 0 ? pink : blue;

  // Convert the photo to a 1-bit dot pattern
  let dithered = ditherImage(img, "atkinson");

  // Random display size — doesn't change the image data
  let w = random(250, 600);
  let h = img.height * (w / img.width);

  // Random position
  let x = random(-50, width - w + 50);
  let y = random(-50, height - h + 50);

  layer.image(dithered, x, y, w, h);
}

The loop body is the same for every image. i % 2 alternates between 0 and 1 as i steps through the array — a simple way to split images across two ink layers. layer.image(img, x, y, w, h) works exactly like p5's image() but draws to the Riso layer instead of the main canvas.

Random layout with a seed

randomSeed(seed); // at the top of draw()

// ...all random() calls follow the same sequence for this seed

function keyReleased() {
  if (key === " ") {
    seed = floor(random(9999)); // new seed from unseeded RNG
    redraw();
  }
}

randomSeed() at the top of draw() locks every random() call in the loop to a reproducible sequence. Press space to pick a new seed — each one is a unique composition you can export and print.

Using your own images

Upload your image files to the sketch folder, then update imagePaths at the top of sketch.js. Add as many paths as you like — the loop handles any number automatically.
