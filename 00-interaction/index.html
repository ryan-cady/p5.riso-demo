Mouse & Keyboard

How to respond to mouse position, clicks, and key presses in p5.js — and the standard patterns for triggering redraws and exports.

Mouse Position

mouseX and mouseY always hold the current mouse coordinates, updated every frame: 

function draw() {
  clearRiso();
  pink.fill(255);
  pink.circle(mouseX, mouseY, 60); // circle follows the cursor
  drawRiso();
}

pmouseX and pmouseY hold the previous frame's position — useful for drawing lines that follow mouse movement: 

function draw() {
  if (mouseIsPressed) {
    pink.strokeWeight(4);
    pink.stroke(200);
    pink.line(pmouseX, pmouseY, mouseX, mouseY);
  }
  drawRiso();
}

Mouse Events

These functions run once when the corresponding event happens: 

function mousePressed() {
  // runs once when the mouse button is pressed down
  redraw();
}

function mouseReleased() {
  // runs once when the mouse button is released
}

function mouseMoved() {
  // runs every time the mouse moves (without a button held)
}

mouseIsPressed

The boolean mouseIsPressed is true as long as a mouse button is held. Useful inside draw() for continuous interaction: 

function draw() {
  clearRiso();
  if (mouseIsPressed) {
    pink.fill(255);
    pink.circle(mouseX, mouseY, 80);
  }
  drawRiso();
}

Key Events

keyPressed() and keyReleased() fire once per key event. The key variable holds the character that was pressed: 

function keyPressed() {
  // runs once when any key is pressed down
  console.log(key); // prints which key was pressed
}

function keyReleased() {
  // runs once when the key is released
}

Use keyReleased() over keyPressed() for one-shot actions like exporting — it won't fire repeatedly if the key is held down.

The Standard Sketch Pattern

Most p5.riso sketches use the same pattern: draw once on load, space bar to regenerate, E to export: 

function setup() {
  createCanvas(825, 1275);
  pixelDensity(1);
  noLoop(); // draw once and stop
}

function draw() {
  clearRiso();

  pink.fill(255);
  pink.circle(random(width), random(height), 100);

  drawRiso();
}

function keyReleased() {
  if (key === " ") redraw();      // new composition
  if (key === "e") exportRiso();  // export current frame
}

Special Keys

The key variable holds a string for regular characters. For special keys, check keyCode: 

function keyPressed() {
  if (keyCode === ENTER)       { /* Enter key */  }
  if (keyCode === BACKSPACE)   { /* Backspace */  }
  if (keyCode === LEFT_ARROW)  { x -= 10; }
  if (keyCode === RIGHT_ARROW) { x += 10; }
  if (keyCode === UP_ARROW)    { y -= 10; }
  if (keyCode === DOWN_ARROW)  { y += 10; }
}

p5 provides constants for common keys: ENTER, BACKSPACE, DELETE, UP_ARROW, DOWN_ARROW, LEFT_ARROW, RIGHT_ARROW, SHIFT, CONTROL, ALT, ESCAPE.
