Transforms

How to move, rotate, and scale the coordinate system in p5.js — and why push() and pop() are essential for keeping transforms under control.

translate()

translate(x, y) moves the origin of the coordinate system. Everything drawn after it is offset by that amount: 

translate(200, 300);
circle(0, 0, 100); // draws at (200, 300) on the canvas

This is useful for drawing shapes relative to a center point, or for placing a group of shapes together without recalculating every coordinate: 

// Draw a cluster centered at (400, 600):
translate(400, 600);
circle(0, 0, 80);
circle(-60, 40, 40);
circle(60, -30, 55);

rotate()

rotate(angle) rotates the coordinate system around the current origin. Angles are in radians by default — use angleMode(DEGREES) to switch: 

rotate(PI / 4);      // 45° in radians (default)

angleMode(DEGREES);
rotate(45);          // same thing in degrees

Rotation always happens around the current origin. To rotate a shape around its own center, translate to that point first, then rotate: 

// Rotate a rectangle around its own center:
translate(400, 300); // move origin to the shape's center
rotate(PI / 6);      // rotate 30°
rect(-100, -50, 200, 100); // draw centered on origin

scale()

scale(s) scales everything drawn after it. Values above 1 enlarge; below 1 shrink: 

scale(2);      // double size
scale(0.5);    // half size
scale(2, 1);   // stretch horizontally only

push() and pop()

Transforms accumulate — each translate() or rotate() adds to what came before it. Without push() and pop(), transforms pile up and affect everything drawn afterward.

push() saves the current transform state. pop() restores it. Wrap any isolated transform in a push/pop pair: 

// Without push/pop — the translate affects everything after it:
translate(200, 300);
circle(0, 0, 80);   // at (200, 300) ✓
circle(0, 0, 40);   // also at (200, 300) — still translated!

// With push/pop — the translate is contained:
push();
  translate(200, 300);
  circle(0, 0, 80); // at (200, 300) ✓
pop();
circle(0, 0, 40);   // back at (0, 0) ✓

The indentation inside push/pop is a convention — it visually marks what's affected. Pairs can be nested inside each other.

Combining Transforms

Transforms apply in order. Translate first, then rotate, to spin shapes around a point on the canvas: 

// 8 rectangles arranged in a circle:
for (let i = 0; i < 8; i++) {
  push();
    translate(width / 2, height / 2); // move to canvas center
    rotate(i * TWO_PI / 8);           // rotate to position
    translate(200, 0);                // move out from center
    fill(255);
    rect(-30, -30, 60, 60);
  pop();
}

Transforms on Riso Layers

A Riso layer keeps its own drawing state, separate from the canvas — so the global push(), translate(), and rotate() above have no effect on shapes drawn to a layer. Calling pink.rect(...) after a global rotate() draws the rectangle un-rotated, at its plain coordinates.

To transform a layer's drawing, call layer.push() / layer.pop() and layer.translate() / layer.rotate() — the same functions, but scoped to that layer: 

pink.push();
  pink.translate(width / 2, height / 2);
  pink.rotate(PI / 4);
  pink.fill(255);
  pink.rect(-100, -100, 200, 200); // rotated 45° around canvas center
pink.pop();

The combining example above works the same way on a layer — just prefix every transform call with the layer name: 

// 8 rectangles arranged in a circle, on the pink layer:
for (let i = 0; i < 8; i++) {
  pink.push();
    pink.translate(width / 2, height / 2);
    pink.rotate(i * TWO_PI / 8);
    pink.translate(200, 0);
    pink.fill(255);
    pink.rect(-30, -30, 60, 60);
  pink.pop();
}
