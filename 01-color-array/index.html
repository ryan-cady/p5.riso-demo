How it works

Click the canvas to pick a new random color from the p5.riso library's built-in color array.

Picking a random color

let i = floor(random(RISOCOLORS.length));
let c = RISOCOLORS[i];

RISOCOLORS is a global array with 81 Risograph ink colors. Each entry has a .name (like "fluorescentpink") and a .color (RGB values).

i is an index number — a random position in the array. random() returns a decimal like 42.739, but array positions must be whole numbers, so floor() rounds it down.

c is the color object at that position. The sketch uses c.color for the fill and c.name for the label.

The pattern

floor(random(array.length)) is a general pattern for picking a random item from any array — you'll use it often.
