p5.js Overview

A quick-reference introduction to p5.js — the creative coding library these demos are built on. Covers the sketch lifecycle, shapes, color, typography, math, interaction, and animation.

What is p5.js?

p5.js is a JavaScript library for creative coding. It gives you a set of simple functions for drawing shapes, working with color, loading images, handling mouse and keyboard input, and animating things on screen — all running directly in the browser.

Every p5.js sketch has the same basic structure: a setup() function that runs once when the sketch starts, and a draw() function that runs on a loop — up to 60 times per second by default.

Sketch Structure

setup()

Runs once at the very start. Use it to create the canvas, set initial values, and configure anything that only needs to happen once. 

function setup() {
  createCanvas(600, 400); // width, height in pixels
  background(240);        // fill the canvas with a light gray
}

draw()

Runs in a loop after setup() finishes — once per frame. Anything you draw here redraws every frame, which is how animation works. Use noLoop() to stop the loop if you only need to draw once. 

function draw() {
  background(240);          // clear the canvas each frame
  circle(mouseX, mouseY, 40); // draw a circle that follows the mouse
}

preload()

Runs before setup(), and p5 waits for it to finish before moving on. Use it to load images, fonts, or data files. Never load files inside setup() or draw(). 

let img;

function preload() {
  img = loadImage("photo.jpg"); // fully loaded before setup() runs
}

function setup() {
  createCanvas(600, 400);
  image(img, 0, 0);
}

The Canvas & Coordinates

The canvas coordinate system starts at the top-left corner, which is (0, 0). X increases to the right, Y increases downward. This is the opposite of math class, but standard for screen graphics. 

// A canvas that is 600px wide and 400px tall:
// top-left  → (0, 0)
// top-right → (600, 0)
// center    → (300, 200)
// bottom-right → (600, 400)

createCanvas(600, 400);

// built-in variables for canvas size:
// width  → 600
// height → 400

Always call pixelDensity(1) in setup() when using p5.riso — it prevents high-DPI screens from scaling the canvas in ways that affect exports.

Shapes

circle(x, y, diameter);          // circle centered at (x, y)
ellipse(x, y, width, height);    // ellipse centered at (x, y)

rect(x, y, width, height);       // rectangle from top-left corner
rect(x, y, width, height, r);    // with rounded corners (radius r)

line(x1, y1, x2, y2);           // line between two points
point(x, y);                     // single pixel

triangle(x1, y1, x2, y2, x3, y3); // three corners

// rectMode changes how rect() is positioned:
rectMode(CENTER); // x,y is the center instead of top-left corner
rectMode(CORNER); // default — x,y is top-left

Color

Color values are 0–255. A single number is grayscale; three numbers are red, green, blue. 

background(255);           // white
background(0);             // black
background(128);           // mid gray
background(255, 0, 0);     // red
background(0, 120, 191);   // riso blue

fill(255, 72, 176);        // set fill color (pink)
fill(200, 80);             // grayscale with opacity (0–255)
noFill();                  // transparent fill

stroke(0);                 // black outline
stroke(255, 0, 0);         // red outline
noStroke();                // no outline
strokeWeight(3);           // outline thickness in pixels

Color settings stay active until you change them — set fill() and stroke() before each shape you want to look different.

Typography

textSize(24);              // font size in pixels
textFont("monospace");     // font family (or a loaded font)
textAlign(CENTER, CENTER); // horizontal, vertical alignment
                           // LEFT / CENTER / RIGHT
                           // TOP / CENTER / BASELINE / BOTTOM

fill(0);
text("Hello world", x, y); // draw text at (x, y)

// measure text width before drawing:
let w = textWidth("Hello world");

Variables & Math

let x = 100;        // declare a variable (can be reassigned)
const SIZE = 40;    // constant (cannot be reassigned)

// Arithmetic
x = x + 10;        // or: x += 10
x = x * 2;

// Useful p5 math functions:
random(low, high);          // random float between low and high
random(myArray);            // random item from an array
floor(3.7);                 // → 3  (round down)
ceil(3.2);                  // → 4  (round up)
round(3.5);                 // → 4  (round to nearest)
abs(-5);                    // → 5  (absolute value)

// map() rescales a value from one range to another:
// e.g. convert a 0–100 data value to a 10–80px size
let size = map(value, 0, 100, 10, 80);

// constrain() clamps a value to stay within a range:
let x = constrain(mouseX, 0, width);

// Trigonometry (angles in radians):
sin(angle);   cos(angle);   // −1 to 1
TWO_PI;       // full circle (≈ 6.28)
PI;           // half circle (≈ 3.14)
radians(90);  // convert degrees → radians → 1.57

Animation & Looping

frameRate(30);   // set target frames per second (default: 60)
frameCount;      // how many frames have drawn so far

noLoop();        // stop draw() from looping — draw once and pause
loop();          // restart the loop after noLoop()
redraw();        // run draw() exactly once while looped off

For Riso sketches that only draw once (most of them), noLoop() in setup() keeps things simple and makes exportRiso() predictable.

Transforms

Transforms move, rotate, or scale the entire coordinate system. Wrap them in push() / pop() so they don't affect anything drawn afterwards. 

push();                  // save current transform state
  translate(300, 200);   // move origin to (300, 200)
  rotate(PI / 4);        // rotate 45 degrees
  rect(-50, -50, 100, 100); // draws centered at the new origin
pop();                   // restore previous transform state
// everything below is back to normal

Angles for rotate() are in radians. Use radians(45) to convert from degrees, or use the built-in constants: QUARTER_PI, HALF_PI, PI, TWO_PI.

Noise

noise() returns smooth, organic-looking random values — unlike random(), nearby inputs give nearby outputs. Useful for flowing shapes and textures. 

// noise() returns a value between 0 and 1
let n = noise(x * 0.01, y * 0.01); // 2D noise at position (x, y)

// Animate over time by passing frameCount as a third argument:
let n = noise(x * 0.01, y * 0.01, frameCount * 0.005);
