Loops & Grids

Using for loops to repeat shapes across a grid — the pattern behind halftones, textures, and repeated motifs.

The for loop

A for loop repeats a block of code, changing one variable each time through. It has three parts, separated by semicolons: 

for (let i = 0; i < 10; i++) {
  circle(i * 40, 100, 20);
}
  • let i = 0 — runs once, before the loop starts
  • i < 10 — checked before every pass; the loop stops once it's false
  • i++ — runs after every pass, incrementing i by 1

That draws 10 circles in a row, each 40px further right than the last — i goes 0, 1, 2 … 9, and i * 40 turns that count into an x position.

Nested loops make a grid

Put a loop inside a loop to cover two dimensions. The outer loop steps down the rows; the inner loop steps across the columns: 

for (let row = 0; row < 5; row++) {
  for (let col = 0; col < 5; col++) {
    let x = col * 60 + 30;
    let y = row * 60 + 30;
    circle(x, y, 20);
  }
}

For every row, the inner loop runs all the way through its columns before the outer loop moves to the next row — so a 5×5 grid draws 25 circles total.

Turning index into position

Hard-coded spacing (like the 60 above) only fits one canvas size. Divide the canvas by the number of columns and rows instead, so the grid scales with createCanvas(): 

let cols = 8;
let rows = 6;
let spacing = width / cols;

for (let row = 0; row < rows; row++) {
  for (let col = 0; col < cols; col++) {
    let x = col * spacing + spacing / 2; // center of each cell
    let y = row * spacing + spacing / 2;
    circle(x, y, spacing * 0.6);
  }
}

Adding variation per cell

Combine the loop with random() to vary each cell instead of repeating one shape identically. Use randomSeed() if you want the variation to be repeatable: 

randomSeed(1);

for (let row = 0; row < rows; row++) {
  for (let col = 0; col < cols; col++) {
    let x = col * spacing + spacing / 2;
    let y = row * spacing + spacing / 2;
    let d = random(spacing * 0.2, spacing * 0.9);
    circle(x, y, d);
  }
}

Wrap each cell in push() / pop() to rotate or scale individual cells without affecting the rest of the grid: 

for (let row = 0; row < rows; row++) {
  for (let col = 0; col < cols; col++) {
    push();
      translate(col * spacing + spacing / 2, row * spacing + spacing / 2);
      rotate(random(TWO_PI));
      rect(-spacing * 0.3, -spacing * 0.3, spacing * 0.6, spacing * 0.6);
    pop();
  }
}

Grids on Riso layers

Everything above works the same on a Riso layer — draw the grid to the layer instead of the canvas. Varying fill() density per cell is what a halftone pattern actually is: 

let pink = new Riso("fluorescentpink");

function draw() {
  clearRiso();

  let cols = 10, rows = 14;
  let spacing = width / cols;

  for (let row = 0; row < rows; row++) {
    for (let col = 0; col < cols; col++) {
      let x = col * spacing + spacing / 2;
      let y = row * spacing + spacing / 2;
      pink.fill(random(80, 255)); // ink density varies per dot
      pink.circle(x, y, spacing * 0.7);
    }
  }

  drawRiso();
}
