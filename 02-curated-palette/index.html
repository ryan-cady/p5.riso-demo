Curated Palette

Build a custom subset of RISO colors and draw swatches

How it works

Draws color swatches from a hand-picked set of RISO ink names. Change the array to build your own palette.

Defining your colors

let myColors = ["fluorescentpink", "blue", "yellow", "orange", "teal"];

An array of strings matching RISO color names (lowercase, no spaces). The full list is on the p5.riso site.

Getting the RGB value

let r = new Riso(myColors[i]);
fill(r.channelColor);

new Riso() creates a Riso layer. Here it's used to grab the RGB preview color from .channelColor for drawing swatches.

i is the loop counter — it steps through 0, 1, 2, 3, 4, drawing one swatch per color.

Auto-sizing

let w = width / myColors.length;

Each swatch width is the canvas divided by the number of colors — add or remove colors and the layout adjusts automatically.
