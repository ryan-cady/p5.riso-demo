Load Image

Use preload() and loadImage() to bring images into P5

View CodeDownload Sketch

How it works

Displays an uploaded image on the canvas. Simple, but the preload() pattern here is critical for every demo that follows.

Loading in preload()

function preload() {
  img = loadImage("../images/lee-scratch-perry.jpg");
}

preload() runs before setup(). P5 waits until everything inside it is fully loaded before continuing. If you load images in setup() instead, the image might not be ready yet and you'll get a blank canvas or an error.

Matching canvas to image

pixelDensity(1);
img.resize(825, 0); // resize to half-letter width
createCanvas(img.width, img.height);

pixelDensity(1) ensures consistent pixel behavior for p5.riso. The image is resized to 825px wide (half-letter at 150 DPI), and the canvas is then sized to match the resized image.

Common issues

This is the most common failure point — wrong filename, wrong folder path, or forgetting to use preload(). Always double-check the path matches your uploaded file.
