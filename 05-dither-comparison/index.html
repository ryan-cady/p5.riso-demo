How it works

Interactive comparison of all four dither algorithms. Press keys 1–4 to switch between them. Move the mouse left and right to change the threshold.

Threshold control

let threshold = map(mouseX, 0, width, 0, 255);

map() converts one number range to another. mouseX position (0 to canvas width) becomes a brightness threshold (0–255). Left side = low threshold (more dots, darker). Right side = high threshold (fewer dots, lighter).

The four dither types

  • "atkinson" — classic Mac look, high contrast, loses some shadow detail
  • "floydsteinberg" — smoother gradients, most common in print
  • "bayer" — ordered grid pattern, very mechanical/digital
  • "none" — hard threshold, not real dithering — everything above the cutoff is white, below is black

See the full ditherImage() reference for details on each algorithm.

Choosing a dither type

Different types suit different images. Portraits often look best with floydsteinberg, while graphic content works well with atkinson.
