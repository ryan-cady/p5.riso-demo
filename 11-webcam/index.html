Webcam Riso

Live webcam feed processed in real time — pink = Atkinson dither, blue = halftone circles. Press f to freeze a frame, then e to export separate Riso layers.

How it works

createCapture(VIDEO) asks the browser for webcam access and returns a live video element. Each frame, we call capture.get() to snapshot the current video into a p5.Image — the same format that ditherImage() and halftoneImage() expect. From there the pipeline is identical to the static image demos.

Step 1: request camera access

function setup() {
  capture = createCapture(VIDEO);
  capture.size(640, 480);
  capture.hide(); // hide the raw <video> element — we draw to canvas instead
}

createCapture(VIDEO) creates a hidden <video> element and starts streaming from the default camera. capture.hide() removes it from the page — we'll render the processed output onto the p5 canvas instead.

Step 2: snapshot each frame and process it

function draw() {
  clearRiso();

  let frame = capture.get(); // snapshot current video frame → p5.Image

  // Pink layer: Atkinson dither
  let dithered = ditherImage(frame, "atkinson", threshold);
  pink.image(dithered, 0, 0);

  // Blue layer: halftone circles
  let halftoned = halftoneImage(frame, "circle", frequency, 45, 100);
  blue.image(halftoned, 0, 0);

  drawRiso();
}

capture.get() returns a static p5.Image copy of the video at that instant. Processing two full-frame images every tick is expensive, so we run at frameRate(6) — slow enough to stay smooth, fast enough to feel live.

Step 3: mirror the frame

let mirrorBuffer = createGraphics(640, 480); // reusable off-screen buffer

function getFrame() {
  if (!mirrored) return capture.get();
  mirrorBuffer.clear();
  mirrorBuffer.push();
  mirrorBuffer.translate(640, 0); // move origin to right edge
  mirrorBuffer.scale(-1, 1);      // flip horizontally
  mirrorBuffer.image(capture, 0, 0);
  mirrorBuffer.pop();
  return mirrorBuffer.get();      // snapshot the flipped result
}

Browsers don't expose a built-in flip for video captures, so we draw into an off-screen createGraphics buffer with scale(-1, 1) applied. The buffer is created once in setup() and reused every frame to avoid repeated allocation. translate(640, 0) shifts the origin to the right edge first, so the flipped image lands in the correct position.

Step 4: freeze, tweak, export

// Press "f" to freeze
if (!frozen) {
  frozenFrame = getFrame(); // snapshot the live stream
  frozen = true;
  noLoop();  // stop the draw loop
  redraw();  // render once with the snapshot
}

// Press "1" to raise threshold while frozen
if (key === "1") {
  threshold = constrain(threshold + 10, 50, 220);
  if (frozen) redraw(); // reprocess the same snapshot with new settings
}

// Press "e" to export
if (frozen) exportRiso();

noLoop() stops the animation loop. While frozen, adjusting 1/2 (threshold) or 3/4 (halftone frequency) calls redraw(), which runs draw() once using the stored frozenFrame. This lets you dial in the look before committing to an export. Press f again to resume the live feed.

Keys at a glance

  • f — freeze the current frame / resume live view
  • e — export Riso layers as separate PNGs (frozen only)
  • m — toggle mirror / selfie mode (live only)
  • 1 / 2 — raise / lower Atkinson dither threshold
  • 3 / 4 — raise / lower halftone dot frequency
