Functions

Three levels of functions — press 1, 2, 3 to switch modes. Press r to redraw.

How it works

This sketch demonstrates three levels of functions, each building on the last. Press 1, 2, and 3 to step through them.

Mode 1: Basic function

function drawCircleStamp() {
  fill(255, 72, 176, 180);
  circle(width / 2, height / 2, 200);
}

A function is a named block of code. You define it once with function, then run it whenever you want by calling its name: drawCircleStamp(). In Mode 1, we call it three times — but since it always does the exact same thing, it draws in the same spot every time. The output never changes.

This is useful for organizing your code, but it gets more powerful when you add parameters.

Mode 2: Function with parameters

function drawRing(x, y, size, col) {
  fill(col);
  circle(x, y, size);
  stroke(col);
  circle(x, y, size * 1.3);
}

Parameters are variables that get filled in when you call the function. They go inside the parentheses. Now the same function can produce different results depending on what you pass in:

drawRing(150, 200, 80, color(255, 72, 176));  // small pink ring
drawRing(300, 350, 140, color(0, 120, 191));   // big blue ring

One function, many outputs. Parameters are what make functions reusable — you write the recipe once, then change the ingredients each time.

Mode 3: Function that returns a value

function pickColor() {
  let colors = [
    color(255, 72, 176, 180),  // pink
    color(0, 120, 191, 180),   // blue
    color(255, 108, 47, 180),  // orange
  ];
  let i = floor(random(colors.length));
  return colors[i];
}

return sends a value back to wherever the function was called. Think of it like a machine with an output slot — you put something in, it does some work, and hands you a result:

let col = pickColor();  // col now holds a random color
drawRing(x, y, size, col);

The return value gets stored in col, which we then pass to drawRing(). Mode 3 combines both concepts — pickColor() returns a color, and drawRing() uses it as a parameter. Press r to regenerate with new random values.

Why functions matter

You've already been using functions this whole time — setup(), draw(), preload(), and keyReleased() are all functions that P5 calls for you. random(), map(), and floor() are functions that return values. Now you can write your own.

Functions keep your code organized, avoid repetition, and make it easier to experiment — change the function once and every call to it updates automatically.
