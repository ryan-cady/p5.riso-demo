Pattern Generator

A grid of rotated arcs in two RISO inks, sized to a full 8.5×11 sheet. Click the canvas for a new layout.

View CodeDownload Sketch

How it works

A nested loop walks a grid of cells. Every other cell (checkerboard-style) gets a quarter-circle arc, rotated to a random multiple of 90° and filled with one of two RISO inks. Click anywhere on the canvas to reroll the whole pattern.

Sizing the canvas to paper

createCanvas(1275, 1650); // 8.5 x 11in sheet at 150 DPI
pixelDensity(1);

RISO prints at 150 DPI, so an 8.5×11in sheet is 1275 × 1650 pixels (inches × 150). See Exporting for Print for the full conversion table. pixelDensity(1) keeps that math accurate on Retina/HiDPI screens, which otherwise double the canvas resolution.

Getting RISO colors

orangeColor = new Riso("orange").channelColor;
tealColor = new Riso("teal").channelColor;

new Riso() creates a Riso ink layer — here it's only used to read its .channelColor, the RGB preview of that ink, so it can be passed to a normal fill() call. This is the same trick used in Curated Palette — grab the color once, reuse it as a plain value.

Building the grid

cols = int(random(6, 13));
rows = int(random(6, 13));

const spacingX = width / cols;
const spacingY = height / rows;

for (let i = 0; i < cols; i++) {
  for (let j = 0; j < rows; j++) {
    const x = i * spacingX + spacingX / 2;
    const y = j * spacingY + spacingY / 2;
    // ...
  }
}

int() rounds down to a whole number — see floor(), which it's equivalent to. Column and row counts are randomized between 6 and 12 each time, and spacingX / spacingY divide the canvas evenly so the grid always fits, no matter how many cells it has. This is the same pattern covered in Loops & Grids.

Skipping every other cell

if ((i + j) % 2 === 0) {
  // draw an arc here
}

% is the modulo operator — it returns the remainder after division. When a cell's column and row indices add up to an even number, (i + j) % 2 is 0, so the condition is true. That leaves every other cell empty, like a checkerboard.

Rotating each arc

push();
  translate(x, y);
  rotate(radians(rotation));
  fill(fillColor);
  arc(0, 0, circleSize, circleSize, PI, 0, CHORD);
pop();

push() / pop() isolate the translate() and rotate() for each cell, so rotating one arc doesn't affect the next. arc(0, 0, ...) is drawn at the local origin — which, thanks to translate(), lands exactly on (x, y). PI to 0 sweeps a half-circle, and CHORD closes it with a straight line instead of through the center, producing the quarter-circle wedge look. More on this in Transforms.

Regenerating on click

function mousePressed() {
  generatePattern();
}

The sketch uses noLoop(), so draw() only runs once on its own. mousePressed() picks new random column/row counts, then calls redraw() to run draw() exactly one more time with the new values.
