Pattern Generator

A grid of rotated shapes across two RISO ink layers, sized to a full 8.5×11 sheet. Click the canvas for a new layout, press "e" to export each layer as a PNG. Open it in the p5 editor to remix it yourself.

How it works

A nested loop walks a grid of cells. Every other cell (checkerboard-style) gets one of two shapes, at its own size, rotated to a random multiple of 90° and drawn onto one of two RISO ink layers. Shape and ink color are picked independently, so any shape can land on either color. Click anywhere on the canvas to reroll the whole pattern, or press E to export each layer as its own PNG.

Sizing the canvas to paper

createCanvas(1275, 1650); // 8.5 x 11in sheet at 150 DPI
pixelDensity(1);

RISO prints at 150 DPI, so an 8.5×11in sheet is 1275 × 1650 pixels (inches × 150). See Exporting for Print for the full conversion table. pixelDensity(1) keeps that math accurate on Retina/HiDPI screens, which otherwise double the canvas resolution.

Setting up two ink layers

layerColor1 = new Riso("orange");
layerColor2 = new Riso("sunflower");

new Riso() creates a separate ink channel — think of it as its own canvas that only holds one color of ink. Each layer is created once in setup() and reused every time the pattern redraws. layerColor1 / layerColor2 are named after their role, not a specific color — swap the color names to try a different combo without renaming anything else in the sketch.

Clearing and compositing

function draw() {
  background(255);
  clearRiso();
  // ...draw shapes onto the layers...
  drawRiso();
}

clearRiso() wipes both layers at the start of every redraw, so the old pattern doesn't stay mixed in with the new one. drawRiso() blends the two layers together and displays the result on the canvas — nothing is visible until it's called.

Building the grid

cols = int(random(6, 13));
rows = int(random(6, 13));

const spacingX = width / cols;
const spacingY = height / rows;

for (let i = 0; i < cols; i++) {
  for (let j = 0; j < rows; j++) {
    const x = i * spacingX + spacingX / 2;
    const y = j * spacingY + spacingY / 2;
    // ...
  }
}

int() rounds down to a whole number — see floor(), which it's equivalent to. Column and row counts are randomized between 6 and 12 each time, and spacingX / spacingY divide the canvas evenly so the grid always fits, no matter how many cells it has. This is the same pattern covered in Loops & Grids.

Skipping every other cell

if ((i + j) % 2 === 0) {
  // draw a shape here
}

% is the modulo operator — it returns the remainder after division. When a cell's column and row indices add up to an even number, (i + j) % 2 is 0, so the condition is true. That leaves every other cell empty, like a checkerboard.

Picking a shape and a layer, independently

const isLayer1 = random() < 0.5;
const layer = isLayer1 ? layerColor1 : layerColor2;

const isShape1 = random() < 0.5;
const type = isShape1 ? shape1Type : shape2Type;
const size = isShape1 ? shape1Size : shape2Size;

Two separate coin flips — one for ink color, one for shape. Because they're independent random() calls, all four combinations show up: shape1 in either color, shape2 in either color. type and size get read off whichever shape won the flip, ready to hand to drawShape().

Rotating each shape onto a layer

const rotation = radians(floor(random(4)) * 90);

layer.noStroke();
layer.fill(255); // full ink density

layer.push();
layer.translate(x, y);
layer.rotate(rotation);
drawShape(layer, type, size);
layer.pop();

A plain, global push() / translate() / rotate() wouldn't affect a Riso layer — a layer keeps its own drawing state, separate from the canvas. So the transforms are called on the layer itself: layer.push() / layer.pop() isolate layer.translate() / layer.rotate() to just this shape, the same way Transforms covers it. After moving the layer's local origin to (x, y) and rotating it, drawShape() just draws at (0, 0) — same as any other rotated shape.

Two shapes, two sizes

let shape1Type = "arc", shape1Size = 80; // try: "arc", "triangle", "square", "circle"
let shape2Type = "triangle", shape2Size = 60;

function drawShape(layer, type, size) {
  if (type === "triangle") {
    layer.triangle(-size / 2, size / 2, size / 2, size / 2, 0, -size / 2);
  } else if (type === "square") {
    layer.rect(-size / 2, -size / 2, size, size);
  } else if (type === "circle") {
    layer.circle(0, 0, size);
  } else {
    layer.arc(0, 0, size, size, PI, 0, CHORD); // quarter-circle wedge
  }
}

Every shape gets drawn centered on the layer's local origin, after it's already been moved and rotated — so adding a new shape is just adding another else if branch that draws something centered on (0, 0) at roughly size across. drawShape() takes type and size as arguments instead of reading a single global, which is what makes two independent shapes possible — shape1Type/shape1Size and shape2Type/shape2Size can each be changed on their own, at the top of the sketch, without touching the drawing logic.

Note that "arc" and "circle" are two different options — "arc" is the quarter-circle wedge the original sketch used (a half-circle sliced by CHORD), while "circle" draws the whole thing with layer.circle().

Regenerating on click

function mousePressed() {
  generatePattern();
}

The sketch uses noLoop(), so draw() only runs once on its own. mousePressed() picks new random column/row counts, then calls redraw() to run draw() exactly one more time with the new values.

Exporting the layers

function keyReleased() {
  if (key === "e") exportRiso();
}

exportRiso() saves each Riso layer as its own grayscale PNG — one file per ink, ready to send to the machine. See Exporting for Print for what to do with the files afterward.
