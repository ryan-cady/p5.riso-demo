Pattern Generator

A grid of rotated arcs across two RISO ink layers, sized to a full 8.5×11 sheet. Click the canvas for a new layout, press "e" to export each layer as a PNG. Open it in the p5 editor to remix it yourself.

How it works

A nested loop walks a grid of cells. Every other cell (checkerboard-style) gets a quarter-circle arc, rotated to a random multiple of 90° and drawn onto one of two RISO ink layers. Click anywhere on the canvas to reroll the whole pattern, or press E to export each layer as its own PNG.

Sizing the canvas to paper

createCanvas(1275, 1650); // 8.5 x 11in sheet at 150 DPI
pixelDensity(1);

RISO prints at 150 DPI, so an 8.5×11in sheet is 1275 × 1650 pixels (inches × 150). See Exporting for Print for the full conversion table. pixelDensity(1) keeps that math accurate on Retina/HiDPI screens, which otherwise double the canvas resolution.

Setting up two ink layers

layerColor1 = new Riso("orange");
layerColor2 = new Riso("sunflower");

new Riso() creates a separate ink channel — think of it as its own canvas that only holds one color of ink. Each layer is created once in setup() and reused every time the pattern redraws. layerColor1 / layerColor2 are named after their role, not a specific color — swap the color names to try a different combo without renaming anything else in the sketch.

Clearing and compositing

function draw() {
  background(255);
  clearRiso();
  // ...draw shapes onto the layers...
  drawRiso();
}

clearRiso() wipes both layers at the start of every redraw, so the old pattern doesn't stay mixed in with the new one. drawRiso() blends the two layers together and displays the result on the canvas — nothing is visible until it's called.

Building the grid

cols = int(random(6, 13));
rows = int(random(6, 13));

const spacingX = width / cols;
const spacingY = height / rows;

for (let i = 0; i < cols; i++) {
  for (let j = 0; j < rows; j++) {
    const x = i * spacingX + spacingX / 2;
    const y = j * spacingY + spacingY / 2;
    // ...
  }
}

int() rounds down to a whole number — see floor(), which it's equivalent to. Column and row counts are randomized between 6 and 12 each time, and spacingX / spacingY divide the canvas evenly so the grid always fits, no matter how many cells it has. This is the same pattern covered in Loops & Grids.

Skipping every other cell

if ((i + j) % 2 === 0) {
  // draw an arc here
}

% is the modulo operator — it returns the remainder after division. When a cell's column and row indices add up to an even number, (i + j) % 2 is 0, so the condition is true. That leaves every other cell empty, like a checkerboard.

Rotating each arc onto a layer

const rotation = radians(floor(random(4)) * 90);
const layer = isLayer1 ? layerColor1 : layerColor2;

layer.noStroke();
layer.fill(255); // full ink density
layer.arc(x, y, circleSize, circleSize, PI + rotation, rotation, CHORD);

Each cell picks one of the two layers at random and draws directly onto it. Riso layers don't pick up the canvas's translate() / rotate() — a layer's shapes always draw in the canvas's untransformed coordinates. So instead of rotating the coordinate system, both arc angles get shifted by the same rotation amount. PI to 0 sweeps a half-circle; adding rotation to both ends spins that same sweep around the arc's center at (x, y) without moving it. CHORD closes the arc with a straight line instead of through the center, producing the quarter-circle wedge look.

Regenerating on click

function mousePressed() {
  generatePattern();
}

The sketch uses noLoop(), so draw() only runs once on its own. mousePressed() picks new random column/row counts, then calls redraw() to run draw() exactly one more time with the new values.

Exporting the layers

function keyReleased() {
  if (key === "e") exportRiso();
}

exportRiso() saves each Riso layer as its own grayscale PNG — one file per ink, ready to send to the machine. See Exporting for Print for what to do with the files afterward.
